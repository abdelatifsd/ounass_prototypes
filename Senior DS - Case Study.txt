Improving Search Ranking
Context
You are given search interaction data from an e-commerce platform.
Each row represents a product impression for a given search query.
Dataset
Name: search_dataset.parquet
* dt 
* timestamp
* user_id
* app_country
* keyword (search query)
* index (position in results)
* product_id
* productclass 
* class
* designer
* name (product title)
* plp_view (if the product is impressed)
* plp_click (if the product is clicked)
* is_converted (if the product is purchased)

Part 1 - Data Understanding & Diagnostics
Goal: assess search quality.
   1. How would you measure search performance using this dataset?
   2. Identify problematic queries
   1. Which queries perform poorly? Why?
   2. How would you define “poor search performance”?
   3. How does position (index) affect clicks? How would you correct for this bias?
   4. Can you segment queries into different intent types? Do different query types behave differently?

Part 2 - Modeling Task (Core)
Task: Build a simple model to improve ranking of search results.
Requirements:
      1. Predict: P(click | query, product, position)
      2. Use available features (and/or engineer new ones)
      3. Output:
      * model approach
      * feature design
      * evaluation method
      * tradeoffs
Part 3 - Search System Design
Our current search system is primarily keyword-based. It retrieves products using keyword matching on product name and attributes. Results are then ranked using a combination of:
      * text relevance
      * product popularity (e.g. clicks)
      * some business rules (e.g. availability)
How would you redesign the search system?
Part 4 - Evaluation & Experimentation


      1. How would you evaluate your model offline?
      2. How would you validate your improvement in production?
Revenue Forecasting for Planning
Context
You are given historical order data from an e-commerce platform.
Goal: forecast future demand to support inventory planning and Open-to-Buy (OTB) decisions.
Dataset 
Name: order_dataset.parquet
      * dt
      * customer_id
      * order_id
      * product_id
      * category
      * soi_store_language
      * market
      * device
      * ordered_qty
      * revenue
Part 1 - Data Understanding
      1. How would you structure the data for forecasting?
      2. Analyze seasonality in the data.
      3. What challenges do you see in this dataset?
Part 2 - Forecasting Task (Core)
Task: Forecast revenue for the next 12 months on:
      1. overall
      2. category x market level
Explain your approach, what models you considered and why.
Part 3 - Evaluation
      1. How would you evaluate forecast accuracy offline?
      2. What matters more than accuracy?
      3. How would you forecast demand for new products/categories?
Deliverables
You are going to present your work to a mix of business and technical audiences, please take this into account when preparing for a presentation.
For the final presentation, please prepare:
      * notebook and slides
      * with a clear explanation of:
      * approach 
      * model
      * assumptions
      * system design (for search)
      * limitations and trade-offs
